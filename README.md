# Video GayMe STORE

Loja virtual de jogos em mídia física (discos e cartuchos) para PC, PlayStation 5, Xbox Series e Nintendo Switch. Projeto acadêmico feito com HTML, CSS, JavaScript, PHP e MySQL.

## O que tem
- Catálogo com busca, filtros por plataforma e categoria e ordenação
- Detalhes do jogo com trailer e avaliações
- Carrinho, lista de desejos e conta do cliente (endereços e cartões)
- Cupons de desconto (primeira compra: `BEMVINDO10`)
- Pagamento simulado e acompanhamento do pedido
- Catálogo +18 (precisa estar logado e confirmar a idade)
- Painel administrativo (`admin.html`)

## Como rodar
1. Copie esta pasta para `C:\xampp\htdocs\`.
2. No XAMPP, inicie **Apache** e **MySQL**.
3. Abra `http://localhost/video-gaymes-store-c/install.php` (cria o banco e os dados).
4. Acesse a loja em `http://localhost/video-gaymes-store-c/`.

Atualizando de uma versão antiga? Use `install.php?recriar=1`.
